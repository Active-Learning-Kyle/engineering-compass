# Hidden role art direction

This document locks the content of the first ten hidden roles before any final
character artwork is accepted. It is deliberately separate from image files so
that scoring and collection behaviour do not depend on an unapproved picture.

## Shared visual rules

- Create a new person for every role. Never recolour or lightly edit a classic
  character.
- Keep the approved Engineering Compass family resemblance: compact full-body
  proportions, simplified geometric faces, faceted flat shapes, restrained
  shading, a shared foot baseline and consistent whitespace.
- Vary age, skin tone, facial structure, hair, body shape and mobility without
  treating any demographic as shorthand for a competency.
- Use one clear action and at most two engineering props. The action must explain
  the role before its name is read.
- Place the competency colours inside clothing panels, tools or the engineered
  object—not as a background wash.
- Export a real transparent background. No white card, checkerboard pattern,
  words, logos, gradient glow, complex scene or poster-like composition.
- Review characters individually before they enter `public/`.

## Ten discovery characters

| Hidden role                 | Competency meaning       | Original character direction                                                                                                                                | Colour structure                                      |
| --------------------------- | ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- |
| Evidence Experimenter       | Problem + Prototype      | Older person comparing a marked test sample with an improved small prototype; attentive, patient posture                                                    | Blue evidence tools + green prototype panels          |
| Collaborative Coordinator   | Planning + Collaboration | Young wheelchair user arranging two teams' interface blocks against one simple milestone strip                                                              | Charcoal plan structure + golden connection points    |
| Iterative Maker             | Hands-on + Prototype     | Middle-aged person kneeling to replace one modular part on a compact mechanism; visibly mid-adjustment                                                      | Orange workwear panels + green revised component      |
| Insight Translator          | Problem + Pitch          | Person with vitiligo turning three evidence tokens into one clear physical diagram for an unseen audience                                                   | Blue source tokens + purple presentation object       |
| Community Advocate          | Collaboration + Pitch    | Older person listening to two small stakeholder tokens and then presenting their shared requirement                                                         | Golden connection details + purple communication prop |
| Delivery Architect          | Hands-on + Planning      | Young person checking a build sequence while fitting the final physical module into place                                                                   | Charcoal sequence map + orange tools and module       |
| Systems Synthesist          | Any exact three-way lead | Person integrating three differently shaped subsystems around one centre; three clothing/prop colour zones are reserved for the actual leading competencies | Exactly the three result colours                      |
| Cross-Disciplinary Catalyst | Any exact four-way lead  | Energetic older person activating four connected modules with a single bridging action; four reserved colour zones                                          | Exactly the four result colours                       |
| Versatile Integrator        | Any exact five-way lead  | Calm young person balancing five compact interfaces around a working core, without extra floating decoration                                                | Exactly the five result colours                       |
| Adaptive Integrator         | All six modes tied       | Distinctive senior figure bringing six small system segments into one working whole; rare but still visually restrained                                     | All six competency colours                            |

For the three-, four- and five-way roles, the final production artwork needs
separate recolourable garment/object zones. A single fixed rainbow raster would
misrepresent the learner's actual combination, so those assets must not be
approved unless their colour regions can be populated from the result data.
